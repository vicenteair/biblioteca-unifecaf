# Biblioteca Digital UniFECAF

Projeto desenvolvido como requisito de avaliação prática da disciplina de Web Design do curso de Análise e Desenvolvimento de Sistemas (ADS) no Centro Universitário UniFECAF.

O objetivo do projeto foi interpretar um protótipo de baixa fidelidade e transformá-lo numa interface web moderna, responsiva, acessível e totalmente alinhada à identidade visual oficial da UniFECAF.

---

## Tecnologias Utilizadas

* HTML5 (Estrutura semântica e acessibilidade)
* CSS3 (Layout com Flexbox, CSS Grid e Media Queries para responsividade)
* Google Fonts (Tipografia Inter)

## Funcionalidades e Destaques

* Cabeçalho Fixo (Navbar): Navegação simplificada pelas seções do site.
* Sobre a Biblioteca: Apresentação da infraestrutura física e digital.
* Acervo de Livros: Exibição em cards flexíveis cobrindo diversas áreas do conhecimento (Direito, Administração, Saúde, Psicologia, Tecnologia e Educação).
* As Unidades: Apresentação dos campi físicos e polos tecnológicos da instituição.
* Design Responsivo: Interface adaptada para navegação fluida em computadores, tablets e smartphones.
* Identidade Visual: Cores e estilos baseados no portal oficial do aluno UniFECAF.
